FAQ

Questions

Is this available now?

Not yet. KideSoft is in development. Waitlist members get early access first, and founding MSPs help decide what gets built.

My RMM isn't NinjaOne. Can I still use it?

Yes. Microsoft 365 and the public checks work for everyone, and you can upload CSV or Excel exports from any other tool. Tell us your RMM on the waitlist form. The most-requested tools get full connections first.

Do you install anything on client computers?

No. KideSoft only reads data through the APIs of tools you already use, with read-only permissions.

How is this different from my RMM's built-in reports?

RMM reports cover one tool and are written for technicians. KideSoft combines several tools into one short report written for the business owner, with your branding.

Where is my data stored? Can I delete it?

We plan to host in the EU. You can export or permanently delete all your data at any time. KideSoft only reads what it needs for the reports.

Can I run it on my own server?

Not at launch. A self-hosted version for Linux and Windows Server is planned for organisations that can't use cloud tools. Tell us on the waitlist form if you need it.

Can I edit a report before it's sent?

Yes. Every report waits for your review by default. Change any line, hide a section, or add your own note.

Does it check compliance with frameworks?

It gives a broad readiness overview: which checks from frameworks like CIS Controls, ISO 27001, NIST CSF and Cyber Essentials your data already supports, and which are missing. It is a guide for planning, not an audit or certification.

I run IT in-house, not an MSP. Is this for me?

Possibly. The same reports work for showing management what IT does. Join the waitlist and mention it.
